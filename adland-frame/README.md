# AdLand Frame v1.0.0

A local image workspace made by **AdLand Studio**.

- Multi-image gallery and drag/drop import
- Image inspector with file details and dimensions
- Non-destructive brightness, contrast, saturation, hue, blur and rotation controls
- PNG export of edited images
- Favorites
- Persian / English with RTL support
- Five visual themes
- Reduced motion option
- Interface sound effects
- Windows x64 installer and portable edition
