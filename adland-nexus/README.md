# AdLand Nexus v1.1.0

A polished Windows desktop command center made by **AdLand Studio**.

## New in 1.1.0

- Persian / English interface with RTL switching
- Focus sessions with custom durations from 5–120 minutes
- Separate configurable break duration
- Optional automatic break after focus completes
- Improved ambient motion, glass surfaces and micro-interactions
- Quick capture modal with Ctrl+K
- Command palette with Ctrl+Shift+Space
- Tasks, notes and snippets with persistent local storage
- Calculator and stopwatch
- Local system information
- Import/export workspace backups
- Reduced-motion accessibility setting
- Accent color customization

## Windows build

`npm install` then `npm run dist`.

The Windows installer and portable executable are generated by the repository's GitHub Actions workflow.
