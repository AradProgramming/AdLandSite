# Roshd | رشد

**Roshd** is a Persian-first study planning and focus workspace by **AdLand Studio**.

## Platforms
Windows, macOS, Android and iOS share the same Flutter codebase. Flutter currently supports deployment to Windows/macOS/Android/iOS; iOS builds require macOS and signing can be added later for store distribution.

## Product
- smart daily/weekly planner
- focus timer with configurable study/break cycles
- exam countdowns and reminders
- subjects + study goals
- notes and quick study log
- flashcards with mastery tracking
- weekly analytics and streaks
- focus environment with built-in generated ambient soundscapes
- selectable alarm tones
- Persian-first UI with English secondary
- local-first storage and clipboard JSON backup/restore
- light/dark visual modes and multiple accent moods
- responsive desktop/mobile navigation

All product copy identifies Roshd as a product of **AdLand Studio**.
